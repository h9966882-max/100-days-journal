# 100日ジャーナル｜同期実装 2.1.0

## 変更範囲

装丁2.0の画像・CSS・4タブは維持。同期JavaScript、状態表示、日付・ひとこと表示のみ変更。
サーバー関数 `j100-sync`（JWT必須）と、Dialyの `j100_*` 専用DB構造を追加・変更。既存Atlas/日記のテーブルと関数は変更していません。

Notion→ミラーは完全な一組を読み終えてからトランザクションで更新。Originalの欠番・重複・必須項目欠落や外部API失敗はエラーとし、既存ミラーを残します。
同期時間・状態を記録し、ブラウザーへ回答の書き込み権限は与えていません。所有者はサーバー設定とSupabaseで検証したメールを照合した後、ユーザーIDで固定。

## 実施済みのローカル試験

Nodeのサーバー試験15ケース：認証/所有者拒否、未設定、112件のページ送り、更新回答の受け渡し、改行と絵文字、必須項目欠落、重複、取得不足、Notion 404、429の再試行上限、同時実行抑制、長いrich-textの取得。

Chromiumのメモリー内DOM試験8ケース：回答表示、更新反映、取得失敗時の表示保持、未設定表示、章・Followの選択、発見/お気に入り、ログアウト後の遅延応答破棄。
通信・Auth・SQLは試験用に置換。履歴操作も試験用置換。公開コードに試験用認証は含みません。
実機Safari/本番Notion API/本番RLSへのリクエストを通した往路確認は未実施です。
